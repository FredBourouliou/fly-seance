# Design context — Fly Séance

## Audience
- DEV Hacktoberfest judges (week 4, "Ghost in the Machine"), who see it first through the article's GIF/video and screenshots, then maybe the repo.
- Developers who clone the repo and run a séance locally (desktop browser, localhost).

## Use cases
- Ask the fly a question and watch its body answer, in about 5 seconds.
- Check that the answer is real: the spike raster, the measured rates against the thresholds, the trial votes.

## Brand personality
Victorian séance meets scientific plate: solemn, precise, a little eerie, never kitsch.
The spiritualism is the costume; the science is the substance. Every number shown is measured.

## Aesthetic direction
- Dark paper, sepia ink, one candle as the only warm light source; typography of an old natural-history plate.
- The fly is the centre: a realistic 3D specimen, as if under a bell jar on the séance table.
- Anti-references: Ouija/velvet/fog gothic, neon "AI demo", dashboard grids, chat bubbles.

## Constraints
- Standard-library Python server + Server-Sent Events; static `web/` (no build step).
- Runs offline on the user's machine (no CDN at run time: vendor any library into `web/`).
- WCAG AA, `prefers-reduced-motion` respected (the verdict must still be readable without motion).
